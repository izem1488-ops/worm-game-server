# Worm Zone — Multiplayer Server

سيرفر Node.js يدير لاعبين حقيقيين بنفس الوقت للعبة دودة الساحة.

## التشغيل محلياً (للتجربة على جهازك)
```
npm install
npm start
```
السيرفر يشتغل على المنفذ 3000 افتراضياً.

## النشر على Railway
1. اربط هذا الـ repo بحساب Railway
2. Railway يكتشف تلقائياً إنه مشروع Node.js ويشغّله بـ `npm start`
3. بعد النشر، يديك رابط عام (مثل `https://your-app.up.railway.app`) — هذا رابط السيرفر اللي تربط فيه ملف اللعبة
